# Tutorials

The tutorials follow the steps of a feature extraction: spikes, sweep features,
sweepset features and cell features, analysing a cell of the Allen Cell Types
Database. The last two show JAX-specific use: compiled calls, batches and
gradients, and fitting a model to features by gradient descent.
